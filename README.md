# ai-trader

A small, honest quantitative research platform for systematic trading strategies.

Built to test ideas properly: backtest → sweep → walk-forward → portfolio.
Fails fast on bad ideas. Documents failures as carefully as successes.

## Status

**Research complete (v0.2.0).** Three strategies tested; none passed the walk-forward gate.
See [`docs/FINDINGS.md`](docs/FINDINGS.md) for the full write-up.
